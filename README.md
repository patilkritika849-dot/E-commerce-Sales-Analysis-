# 🛒 E-Commerce Sales Analysis

This project analyzes E-Commerce sales data to understand product performance, profit, and monthly sales trends using Python.

### 📂 Dataset
The dataset contains:
- `Product`: Name of the product (Mobile, Laptop, Headphones, etc.)
- `Sales`: Sales amount
- `Profit`: Profit earned
- `Month`: Sales month (Jan, Feb, etc.)
